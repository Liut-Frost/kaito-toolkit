# Kaito Toolkit

> Building professional TradingView tools while learning software development.

## Vision

Kaito Toolkit is an open project focused on creating clean, reliable TradingView indicators and trading utilities based on the Kaito trading model.

This project is also a learning journey in software development, Git, GitHub, Pine Script, JavaScript, and Python.
